# EmojiMasker

An iOS app that uses the camera to detect faces and overlay emojis in real-time. Features include front/back camera switching and face tracking.

## Requirements

iOS 18+

Xcode 16+

## Setup
Clone the repository.

Open `EmojiMasker.xcodeproj` in Xcode.

Build and run on an iOS device.

## Features
Face detection with Vision framework.

Emoji overlays scaled to cover faces.

Camera switching with toast feedback.
